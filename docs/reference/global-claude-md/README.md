# 全局 `~/.claude/CLAUDE.md` 版本归档

本目录存放**个人全局** `~/.claude/CLAUDE.md`（跨项目工作规则）的历史快照。

## 为什么放在这里

全局文件位于 `~/.claude/CLAUDE.md`，**不在任何仓库里**——换机器、误覆盖、AI 工具改写都会
让它无声消失，且没有 `git log` 可回溯「上一版写了什么、为什么改」。0001 就是这么丢的：
它曾被放在本仓 `temp/CLAUDE_COMMON.md`，而 `temp/` 在 `.gitignore` 里 →
删除后仓库无痕，最终是从 Claude Code 会话 transcript 里逐字复原的（见下表备注）。

本目录**只是归档，不是权威源**。运行时生效的永远是 `~/.claude/CLAUDE.md` 本体；
这里的文件不被任何工具读取。

## 命名规约

```
NNNN_<一词定位>[.<语言标签>].md
```

- `NNNN` 四位序号，与 `backend/alembic/versions/` 的约定一致，**按生效先后单调递增**
- 无语言标签者 = **权威原版**（全局文件本体的字节副本），其余为该版本的语言变体
- 译文**不占新序号**——它不是新版本，是同一版的另一种呈现

## 更新规程

**换新版全局 CLAUDE.md 之前**（不是之后）：

1. 把当前 `~/.claude/CLAUDE.md` 原样复制进本目录，按上节命名规约编号 +1
2. 在上面的版本表补一行：生效期 / 定位 / 备注；有译文的一并链上
3. 若新版**删掉了**旧版的内容，逐条判定该内容是否仍需要：
   仍需要的搬进项目 `CLAUDE.md`（技术细节）或 memory（一次性 runbook 与事故档案），
   并在本 README 记录迁移落点——否则等于静默丢弃规则

快照**保持逐字原样**（不加编者注、不重排），这样 `git diff 0001 0002` 才有意义；
说明性内容一律写在本 README。

> 归档 ≠ 授权修改。未经用户明确要求不得改动全局文件本体。
