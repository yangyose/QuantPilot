## 1. 概述

### 1.1 背景：这把尺子量错过一次，而所有后续决策都要用它

C1-2（风险调整动量）判定期实测暴露：现行「日级 Rank IC + 月聚合 t 检验」有四处系统性弱点，
其中**重叠窗口高估显著性**已经实际产生过错误结论——朴素 t 检验说 momentum 三状态
「全部高度显著」，改用 Newey-West（HAC, lag=20）后 `6.83 → 2.32`，主导状态 OSCILLATION
从 `4.21` 掉到 **`1.33`（不显著）**。有效样本仅名义的 **8~12%**。

而 **C2 Piotroski / C3 低波动 / C4 资金动向 及后续所有因子决策都要用这把尺子**。
体检报告 §9.1 的定性是：**先有尺子，再改规则**——D-EXIT（退出规则重建）与 E-LOOP
同样排在本主题之后，因为 IC 面板测的是横截面预测力，**评价不了退出时机**。

2026-08-31 C1+P0 上生产后又暴露第五处缺口（K-FACTOR，见 §1.2）：想验证 C1-3 是否生效，
发现**痕迹根本不存在**——不是查不到，是生产从未记录因子级指标。

## 2. 【设计待定】各子项详细设计

本文档 v0.1 仅完成启动核查。以下为已识别、须在 v0.2 详细设计展开时定案的问题：

1. **【设计待定：扩展统计量的持久化结构】** —— roadmap 要求「落新表避免动现有热表」。
   需定：新表名与列、与 `factor_ic_window_state` 的关系（`row_type` 复用还是独立表）、
   唯一键（C0 曾因唯一约束撞车付出代价，见 v1_5_c §2）。定案后先回写 `system_design §4`。

2. **【设计待定：K-6 的因子级粒度与来源】** —— 现 `extract_strategy_z` 取策略级 `z_raw`
   （C0 补丁 `strategy_z_all` 已覆盖权重 0 策略）。因子级需要在 `Scorer.aggregate` 之前
   截取原始因子矩阵。须定：在哪一层截取、是否落有效（非 NaN）率、是否对所有策略一视同仁。

3. **【设计待定：K-7 holdout 区间的具体划法】** —— 候选方案是把面板窗口
   `2024-07 ~ 2026-07` 的**近端**（约最后 6 个月）留作 holdout，改造期只用前段。
   张力在于近端样本同时也是最相关的样本。须定：区间、是否随时间滚动、解锁条件。

4. **【设计待定：K-5 成本模型口径】** —— 换手成本需要佣金 / 印花税 / 滑点假设。
   回测引擎已有滑点情景（V1.5-A A1b），须定是否复用同一套参数以免两处口径分叉。

5. **【设计待定：重跑的执行边界】** —— 面板重跑只能在第二台 24h 算力机（运维红线①，
   生产 2GB 机禁止全 universe 评分）。须定：重跑窗口、单配置还是多配置、
   与 `ic_baseline_pre_c1` 等既有产出的关系（该库**已禁止再 sync**）。

## 3. 【设计待定】测试计划与收尾门槛

按 CLAUDE.md §5.2 与 §4.11 判据选型，本主题**测试形态需特别注意**：本主题产出的是
「用于判断其他东西对不对」的度量，**它自己错了不会有人发现**——没有更上层的尺子来量它。

因此至少须包含：

- **对照实现**：HAC 估计量在构造数据上与已知解析解比对（不能只测「不抛异常」）
- **「改输入 → 结果必须变」**：重叠度改变时有效样本数与 t 值必须相应变化
- **退化输入**：横截面无方差 / 样本不足 / 全 NaN 时的行为须显式定义并断言
- ⚠️ **不得用本主题的产出去验证本主题的正确性**（自证）

具体用例待 v0.2 展开。
